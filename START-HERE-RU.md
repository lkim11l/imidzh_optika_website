# Имидж Оптика — открыть в VS Code и загрузить на GitHub

Архив содержит текущую версию staging-сайта с последней правкой блока «С 2002 года / Оптика HOYA / Личный подход».

## Запуск

1. Распакуйте архив в отдельную папку.
2. В VS Code выберите File → Open Folder и откройте папку imidzh-optika-github.
3. Установите Node.js 20 или новее, если он ещё не установлен.
4. Откройте Terminal → New Terminal и выполните:

   npm start

5. Откройте http://127.0.0.1:4173 в браузере. Для остановки нажмите Ctrl+C в терминале.

Установка npm-пакетов для запуска не требуется. Не открывайте index.html двойным щелчком: сайт использует JavaScript-модули и маршруты.

## Где редактировать

- dist/index.html — главная страница и общий каркас.
- dist/assets/styles.css и dist/assets/shop.css — оформление и адаптивность.
- dist/assets/app.js — навигация и взаимодействия.
- dist/assets/data/products.js — демонстрационные товары.
- dist/assets/ — изображения и остальные ресурсы.

После изменений главной страницы выполните npm run build: команда обновляет HTML-файлы маршрутов в dist. Папка dist — готовый сайт для статического хостинга.

## GitHub через VS Code

1. Откройте Source Control и нажмите Initialize Repository.
2. Добавьте файлы в индекс (Stage All Changes), введите сообщение Initial website и сделайте Commit.
3. Нажмите Publish Branch / Publish to GitHub, войдите в свой аккаунт и выберите приватный репозиторий, если хотите сохранить текущий режим доступа.

В репозиторий загружайте всё содержимое папки проекта, включая dist, scripts, package.json и .gitignore. Загружать ZIP вместо исходников не нужно.

Публикация репозитория на GitHub сама по себе не запускает сайт. Для отдельного развёртывания используйте статический хостинг с каталогом публикации dist. Текущие абсолютные ссылки рассчитаны на корень домена; для GitHub Pages по адресу username.github.io/repository/ потребуется адаптация путей.

## Состояние проекта

Товары, цены и формы — демонстрационные. Отправка заявок, платежи и CS-Cart ещё не подключены. Избранное и корзина сохраняются локально в браузере. Исходный сайт optika77.ru не изменяется.

В архив не включены история Git, привязка к аккаунту Sites и снимки проверок. Оригинальные README.md и ASSETS.md содержат технические сведения и происхождение изображений. Скрипты verify требуют отдельно доступного Playwright; для обычного запуска они не нужны.
