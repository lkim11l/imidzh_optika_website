# Эксперимент: первый экран Имидж Оптика

Изменён только существующий первый экран главной. Supabase, авторизация, админка, каталог, товары, корзина, избранное и остальные секции не изменялись. Изображение — редакционная визуальная концепция, а не SKU; подписи описывают подбор очков и услуги салона, а не подтверждённые характеристики показанной модели.

## Файлы
Изменён: dist/index.html (hero и ссылки на два изолированных ресурса).
Добавлены:
- dist/assets/hero-glasses.css — стили только .hero-experiment, адаптивность и вступление.
- dist/assets/hero-glasses.js — необязательный небольшой параллакс.
- dist/assets/hero/exploded-glasses.webp — оптимизированное изображение.
- experiments/hero-original.html — оригинальный фрагмент hero.
- scripts/revert-hero.mjs — откат только hero и его подключений.
- scripts/verify-hero.cjs — проверки hero с изолированными ответами каталога.
- HERO-EXPERIMENT.md — эта инструкция.

Исходные styles.css и app.js оставлены без изменения. Прежний hero.webp сохранён. Оригинальный генератор страниц при npm run build копирует главную в HTML-оболочки маршрутов. После проверки сборки оболочки маршрутов восстановлены без изменений; в пакете нет файлов страниц каталога или товаров.

## Картинка и композиция
PNG RGBA 1672 × 941, 848 302 байта → WebP RGBA того же размера, 203 988 байт (примерно на 76% меньше). Качество WebP 92, transparency сохранена. Изображение не перерисовывалось и не добавлялось в каталог. Установлены intrinsic width/height, aspect-ratio контейнера и fetchpriority=high; lazy-loading нет.

## Движение
Текст: 0–0,9 с. Очки: 0,3–1,0 с, fade + подъём 12 px + scale от 0,985 до 1. Подписи: последовательное появление от 0,7 до 1,41 с. Параллакс начинается после вступления, только при ширине от 1024 px и точном указателе с hover: максимум 6 px горизонтально, 4 px вертикально, rotateZ 0,75° и rotateY 1,2°. requestAnimationFrame работает только пока движение сходится к цели. Уход указателя, уход hero с экрана, скрытие вкладки и изменение motion-настроек сбрасывают эффект.

## Мобильный экран и доступность
До 900 px: одна колонка; текст, CTA, спокойная строка услуг, затем очки. Подписи и линии скрыты. До 540 px основная кнопка на всю ширину. При reduced motion все элементы сразу в конечном положении, параллакс выключен. Без JS hero остаётся видимым и завершённым; функции сайта, которые и раньше требовали JS, сохраняют это требование.

Существующий редактор текстов главной по-прежнему имеет приоритет: если в базе уже сохранены heroTitle или heroLead, они заменят соответствующий текст из HTML. В рамках эксперимента это поведение не изменялось, содержимое базы не менялось.

## Локальная установка и просмотр
Это пакет изменений для существующего проекта. Остановите сервер. Распакуйте архив отдельно и запустите INSTALL.cmd; выберите папку существующего проекта. Установщик создаст резервную копию, скопирует только перечисленные файлы и не затронет .git или настройки проекта. Он не проверялся на Windows в этой сессии (среда Linux).

Можно установить вручную: скопируйте dist, experiments, scripts и HERO-EXPERIMENT.md из пакета в существующую папку, заменив только совпадающие файлы. В архиве эти папки содержат только изменения hero.

В VS Code в прежней папке: npm start. Откройте http://127.0.0.1:4173/ и нажмите Ctrl+F5. Проверьте локально до публикации.

## Откат
В корне существующего проекта выполните:
node scripts/revert-hero.mjs

Это возвращает оригинальную разметку hero и удаляет подключения экспериментальных CSS/JS из главной. Скрипт не меняет другие секции, подключение базы или админку. Новые неиспользуемые файлы можно оставить. Повторный запуск без экспериментального hero ничего не записывает. Если после публикации вы уже генерировали все маршрутные HTML через build, после отката повторите npm run build для обновления этих оболочек.

## Проверки
- npm run build: успешно.
- Новый verify-hero.cjs: успешно, Chromium, ширины 390/430/768/1024/1280/1440/1920, кнопки записи и коллекции, мобильная навигация, пределы параллакса, reduced motion (включая переключение), отсутствие движения на планшете, без JS, отложенная загрузка картинки с нулевым сдвигом hero, нет runtime/console ошибок.
- Существующий verify.cjs: полный запуск останавливается на устаревшем утверждении о заголовке «Мир в деталях». Сам тест не изменён. Его существующая проверка адаптивности отдельно прошла.
- Существующий verify-refinement.cjs: успешно, 24 изображения, 8 размеров и fallback изображений.
- При увеличении шрифта до 200% сам hero не переполняется. У старой шапки и категории есть переполнение на 1440 px при этом увеличении; они не изменялись. На обычных проверенных ширинах горизонтальной прокрутки нет.
- Откат проверен на отдельной копии: исходный index.html восстанавливается побайтно.
- Сравнение контрольных сумм: среди существовавших файлов изменён только dist/index.html.

Тесты каталога использовали изолированные ответы Supabase и существующие демонстрационные товары; реальных изменений данных не было. В тестовых скриншотах использован системный fallback шрифта, без загрузки Google Fonts. Публикация, deploy и push не выполнялись.

Для повторного запуска нового теста нужен Playwright с Chromium. Сначала запустите npm start, затем: node scripts/verify-hero.cjs. Не требуется пароль администратора.
