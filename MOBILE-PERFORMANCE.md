# Проверка мобильной скорости

Дата: 2026-10-11

Lighthouse, мобильный профиль с замедлением сети и процессора, пустой кеш. Это лабораторные измерения, не статистика настоящих посетителей.

| Показатель | Локальная версия до | Локальная версия после |
|---|---|---|
| Оценка | 71 | 84 |
| Первое содержимое (FCP) | 3.3 s | 2.3 s |
| Крупнейший элемент (LCP) | 5.6 s | 4.2 s |
| Блокировка (TBT) | 120 ms | 30 ms |
| Сдвиги (CLS) | 0 | 0 |

Отдельный замер опубликованного https://optikim.ru/: 80/100; FCP 2.6 s; LCP 4.3 s. Результат публичного сайта нельзя напрямую сравнивать с локальным: отличаются сеть, сервер и сжатие ответов.

Исправления: шрифт Manrope загружается с сайта; 15 локальных CSS-файлов объединены и сжаты в один с хешем имени; фотографии получают подходящий размер через srcset; первый кадр имеет отдельный адаптивный постер и не загружается повторно до прокрутки; главная картинка на телефоне появляется без задержки; чтение размеров текста сгруппировано; настроено кеширование общего CSS и шрифта. Сборка очков при прокрутке сохранена.

Замечание об изображениях уменьшилось с 402 до 94 КиБ. Остаются дополнительные возможности улучшить стили и отдельные изображения. Оценка не фиксированная: одиночные запуски дают разброс.

Новые оптимизации пока локальные. Для публикации обновить dist, scripts, package.json, package-lock.json и vercel.json; затем повторить PageSpeed Insights по https://optikim.ru/. npm run build требует установки devDependencies (clean-css).

Отчёты: mobile-before.json, mobile-after.json, mobile-live.json.
